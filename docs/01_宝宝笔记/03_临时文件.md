  1. 继续拆 indicatorPanelComponents.tsx

  现在已经拆了 Vol、RSI、MA、MMF、SQZMOM、MR，但 indicatorPanelComponents.tsx 里还堆着 MACD、Stoch、TSI、VI、DPO、VDO、AO、VMI、VWAP、MMAD。

  下一步最适合拆的是：

  - DpoSettingsPanels.tsx：刚刚已经把样式行统一了，依赖更干净，适合独立。
  - VwapSettingsPanels.tsx：它是主图指标模板，拆出去价值高。
  - MmadSettingsPanels.tsx：和 VWAP 很像，可以作为主图指标模板对照。

  2. 抽“输入行”公共组件

  现在已经有：

  - NumberBox
  - IndicatorSelectRow
  - IndicatorLineStyleRow
  - IndicatorColorStyleRow
  - IndicatorLineValueStyleRow

  但普通数字输入行还在重复写：

  <label className="ff-indicators-input-panel-v1__row">
    <span className="ff-indicators-input-panel-v1__label">长度</span>
    <span className="ff-indicators-input-panel-v1__control">
      <NumberBox ... />
    </span>
  </label>

  可以抽成：

  - IndicatorNumberRow
  - IndicatorCheckboxRow
  - IndicatorSection

  这样新增指标的输入 tab 会更像配置表，而不是手写布局。

  3. 给新增指标流程补测试模板

  现在有接入文档，但还可以补一个测试模板，比如：

  - indicatorSettingsSchema 是否包含新指标 settings
  - indicatorDefinitions 是否存在列表行
  - chartIndicatorRequestBuilderV2 是否能正确发出请求
  - 默认 settings 是否能 normalize

  这样以后加新指标，不容易漏。

  4. 清理 indicatorPanelShared.tsx

  这个文件现在还混着：

  - option 列表
  - 文案
  - updateSettings 函数

  可以继续拆成：

  - indicatorPanelOptions.ts
  - indicatorPanelText.ts
  - indicatorSettingsPatchers.ts

  这会让面板文件 import 更清楚。

  5. 乱码代码专项清理

  UI 当前能看，但代码里还有历史乱码。建议专门一刀做：

  - 只清理指标面板相关乱码
  - 不碰算法、不碰持久化、不碰渲染
  - 清理后跑 build + 截图人工看 UI

  我建议下一刀先做第 1 点：拆 DpoSettingsPanels.tsx。DPO 已经刚被统一控件处理过，拆它风险最低，而且能继续减少 indicatorPanelComponents.tsx 的体积。
