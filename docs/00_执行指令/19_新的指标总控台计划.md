# 指标总控台

它的加载顺序应该是这样的。

1. 我从指标模块，点击挂载，这个时候，指标直接，接入的是总控台。
2. 总控台第一步，看到指标加载后，应该先明白这个指标。是什么类型的指标
   3. 比如，主图指标，副图指标。
   4. 需要计算指标，不需要计算指标，比如，VOL就是不需要计算的指标。
   5. 但是，Vol 指标中有一条vol均线需要计算。
   6. rsi,stoch 都是需要计算的指标
   7. 当期计算指标，需要前期数据计算的指标
   8. 比如，大部分指标，都需要前期的预热数据。
   9. vwap 这个指标，是基本上唯一的，只需要当前计算的指标。
10. 总控台，理解指标的算法后，就知道需要什么数据了。
11. 所以，它会去历史窗口合并器里，拿到数据，然后交给指标计算，指标计算后，它把结果返回给，历史窗口合并器中。同时，它应该能够告诉历史窗口合并器，这属于主图还是副图的指标，所以，未来如果，交给Klinechart 渲染的时候，这块数据是要放到主图还是副图要有明确的知道。
12. 然后，它会找到实时窗口合并器，拿到数据。给指标计算，然后把结果加载到实时窗口。这个时候，实时窗口的加载应该，找官方那种模式，因为需要可能实时跳动的一些实现。
13. 接着，就是，如果碰到指标需要前置数据，这里面，总控台需要有一个下属模块，这个模块，把指标需要的前置数据多少，要知道。知道后，比如，它得知历史数据窗口这一页，第一根指标，要显示，需要前面的多少数据，才能够完成计算？然后，就向需求切片器，请求这段数据，需求切片器，根据分页器，获得数据，然后给预热模块。通常，历史页都需要前一页的尾部的一些数据。
14. 然后，就是，实时窗口也需要预热，而这个预热的数据，通常就是从第一页开始找。也就是它的预热数据，其实直接找历史窗口数据，就可以找到。然后，加载。
15. 所以，历史窗口的指标，和实时窗口的指标。通过总控台分别加载。
16. 最后，视觉上是连接在一起的，但是，其实是分开计算的。
17. 也就是，总控台看到指标需要什么数据，分别抓取，分别交给指标计算，分别挂载。
18. 最后的，结果就是，历史数据窗口+实时数据窗口，都有了指标数据。
19. 然后，Klinechart 翻译器，把这个数据，翻译成友好数据。
20. 然后，就是翻入渲染前置数据合并器。
21. 然后，进入，分层缓存模块。也就是说，合并到历史数据窗口+实时数据窗口后，接下来走的流程跟K线是一样的了。

 完成的核心点：

  1. 指标类型协议
      - 指标定义现在能声明：
          - paneRole: 'main' | 'sub'
          - renderRole
          - calculationMode
          - warmup
          - paneId
  2. 指标结果结构
      - 指标 series 现在携带：
          - id
          - paneRole
          - paneId
          - renderRole
          - calculationMode
      - 后面 Klinechart 翻译器可以知道它该进主图还是副图。
  3. 挂载状态模块
      - 新增 indicatorRuntimeV2
      - 支持 mount / unmount / update / list / clear
      - 未来指标抽屉点击挂载，应该进这个 runtime，不直接找窗口。
  4. 预热规划模块
      - 新增 indicatorWarmupPlannerV2
      - 能算：
          - 指标需要多少前置 K 线
          - 当前已有多少
          - 缺多少
      - 目前先做规划，不新造查询链。后面接需求切片器时，就从这里拿 missingRows。
  5. 历史 / 实时总控台入口升级
      - 历史窗口请求会生成完整 context：
          - K 线窗口数据
          - pane 信息
          - calculation mode
          - warmup plan
      - 实时窗口也一样，并且可拿 historyRows 作为实时预热参考。
  6. 实时指标刷新入口
      - 新增 refreshRealtimeWindowIndicatorsV2
      - tick 更新完实时 K 线后，未来调用这个刷新实时指标。
      - 没把异步指标计算塞进 mergeMt5RealtimeTickIntoWindow，保持实时 K 线合并器干净。
