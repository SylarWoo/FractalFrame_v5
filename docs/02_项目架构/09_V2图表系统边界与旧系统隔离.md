# V2 图表系统边界与旧系统隔离

## 目标

V2 图表系统的新能力只进入 `ChartWorkspaceV2`、`klineChartRendererV2`、`indicatorRequestV2`、`realtimePageWindowV2` 等新链路。

旧 `ChartCoreHost.tsx` 保留为旧图表宿主，不再承载以下新能力：

- V2 历史页/实时页合并窗口。
- V2 指标总控台、复合指标依赖、指标计算缓存。
- 刷新后视角恢复、跳页移动、实时尾部更新。
- KLineChart V2 overlay、实时分界线、V2 benchmark。

## 当前 V2 边界

- `ChartWorkspaceV2.tsx`：组合历史窗口指标、实时窗口和 render frame。
- `klineChartRendererV2/KLineChartHostV2.tsx`：React 宿主，只负责 chart 生命周期。
- `klineChartRendererV2/klineChartFrameApplyControllerV2.ts`：处理 pane-only、tail-update、full-frame。
- `klineChartRendererV2/klineChartOverlayControllerV2.ts`：统一管理 overlay 安装、更新、销毁。
- `indicatorRequestV2`：指标请求、预热、依赖编排、计算缓存。
- `realtimePageWindowV2`：实时页窗口构建和 tick 合并。

## 迁移原则

新增图表能力优先进入 V2。

旧系统需要兼容时，只做隔离适配，不把 V2 的业务链路复制回旧宿主。

如果必须改 `ChartCoreHost.tsx`，先判断是旧功能修复还是 V2 能力迁移。V2 能力迁移应通过新模块完成，再由旧系统选择性调用适配层。
