# 工作区配置档案模块

本文档记录工作区配置档案模块的边界。这个模块用于把浏览器里的工作区设置保存到本地文件，并按端口隔离。

## 1. 模块命名

中文名：

```text
工作区配置档案模块
```

代码名：

```text
workbenchProfile
```

当前不是账号系统，不叫 account。它是本机开发环境下的配置档案。未来如果接入账号，可以把 `profileId` 从端口档案升级为账号 ID。

## 2. 当前隔离规则

当前按浏览器访问端口隔离。

例如：

```text
http://127.0.0.1:5185 -> port-5185
http://127.0.0.1:5186 -> port-5186
```

两个端口使用不同的状态文件，互不干扰。

## 3. 文件路径

5185 的工作区配置档案：

```text
frontend/.fractalframe-dev/profiles/port-5185/workbench-profile.json
```

5186 的工作区配置档案：

```text
frontend/.fractalframe-dev/profiles/port-5186/workbench-profile.json
```

视角状态也按端口隔离：

```text
frontend/.fractalframe-dev/profiles/port-5185/chart-viewport-state-v4.json
frontend/.fractalframe-dev/profiles/port-5186/chart-viewport-state-v4.json
```

旧文件仍作为迁移 fallback：

```text
frontend/.fractalframe-dev/persistent-state.json
frontend/.fractalframe-dev/chart-viewport-state-v4.json
```

如果新端口档案不存在，系统会先读旧文件；后续写入会落到新的端口档案里。

## 4. 服务端入口

Vite dev server 提供两个本地端点：

```text
/__fractalframe_persistent_state
/__fractalframe_chart_viewport_state
```

关键文件：

```text
frontend/vite.config.ts
```

`persistentDevStatePlugin` 负责普通工作区设置。

`chartViewportDevStatePlugin` 负责图表视角状态。

这两个插件都会从请求的 `Host` 里解析端口，然后映射到对应 profile。

## 5. 前端入口

前端所有设置读写继续走统一 persistence API：

```text
frontend/src/workbench/persistence/jsonStorage.ts
```

业务模块仍然使用：

```text
readJson
writeJson
readString
writeString
readBooleanFlag
writeBooleanFlag
removeStorageItem
```

这些 API 会先读浏览器 localStorage。如果 localStorage 被清空，则会向 Vite dev endpoint 请求当前端口对应的 profile 文件。

当前 profile id 辅助模块：

```text
frontend/src/workbench/settingsProfile/workbenchProfile.ts
```

## 6. 应该保存的内容

工作区配置档案适合保存：

- 当前加载的指标。
- 指标参数。
- 指标快捷菜单。
- 策略加载状态。
- 右侧抽屉打开状态、宽度、当前 tab。
- 底部抽屉状态、高度。
- 设置抽屉中的图表设置。
- MT5 Import Center 自选列表、快捷周期、表格状态。
- 当前 symbol、period、当前页配置。
- KLineChart 横向视角和 Y 轴恢复状态。

## 7. 不应该保存的内容

不要把这些放进 profile：

- 大量 K 线原始数据。
- 指标计算缓存。
- 实时 tick buffer。
- 性能 trace。
- `.dev-logs`。
- 调试 probe 大文件。

这些属于缓存或调试数据，不是工作区配置档案。

## 8. 未来账号扩展

未来如果做账号系统，可以把 profile 路径从：

```text
profiles/port-5185/workbench-profile.json
```

升级为：

```text
profiles/account-{accountId}/workbench-profile.json
```

或者：

```text
profiles/{accountId}/{workspaceId}/workbench-profile.json
```

端口档案仍可作为开发环境默认档案。
